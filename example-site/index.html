FAK LABS — TikTok Profile Search API

API: GET /?u=<username> — search. GET /profile?u=<username> — full profile. GET /videos?u=<username>&limit=30 — profile videos with download links (limit 1–90, cursor pages further). No key, no login. Full docs in the repo.
